개인정보처리방침

rclone-backup · 시행일 2026-10-06

1. 무엇에 접근하나요

rclone-backup은 소유자가 직접 허용한 경우에만 소유자의 구글 드라이브에 접근하며, 백업 파일을 올리고 목록을 확인하는 데에만 사용합니다.

2. 어디에 쓰나요

백업 외의 목적으로 쓰지 않습니다. 구글에서 받은 정보를 제3자에게 전송·판매·공유하지 않으며, 광고나 분석에 쓰지 않습니다. 별도의 서버가 없어 데이터는 소유자의 컴퓨터와 소유자의 구글 드라이브 사이에서만 오갑니다.

3. 어디에 저장되나요

구글 로그인 인증 정보는 소유자의 컴퓨터에만 저장됩니다.

4. 권한을 거두려면

언제든 구글 계정 › 보안 › 타사 앱 액세스에서 접근 권한을 해제할 수 있습니다.

5. 구글 API 사용자 데이터 정책 준수

rclone-backup이 구글 API로 받은 정보를 사용하고 전송하는 방식은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

6. 문의

구글 로그인(동의) 화면에 표시되는 지원 이메일로 문의할 수 있습니다.

Privacy Policy (English)

rclone-backup accesses its owner's Google Drive only with the owner's permission, solely to upload backup files and list them. Information received from Google APIs is not used for any other purpose, and is never transferred, sold, or shared with third parties or used for advertising. There is no server: data moves only between the owner's computer and the owner's Google Drive, and sign-in credentials are stored only on the owner's computer. Access can be revoked at any time at myaccount.google.com/permissions. rclone-backup's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: the support email shown on the Google consent screen.
