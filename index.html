rclone-backup

개인용 구글 드라이브 백업 도구

rclone-backup은 소유자 한 사람이 자기 컴퓨터의 작업 폴더를 자기 구글 드라이브에 정기적으로 백업하기 위해 만든 개인용 설정입니다. 오픈소스 프로그램 rclone을 사용하며, 일반 사용자를 위한 서비스가 아닙니다.

  • 파일은 소유자의 컴퓨터와 소유자의 구글 드라이브 사이에서만 오갑니다.
  • 별도의 서버가 없고, 다른 사람의 데이터를 다루지 않습니다.

개인정보처리방침 (Privacy Policy)

rclone-backup is a personal configuration that lets its owner back up folders from their own computer to their own Google Drive, using the open-source tool rclone. It is not a service for the public. See the privacy policy.
